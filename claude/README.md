# Scuba

Bring your saved context into your conversation. Search and read Captures and Collections, save notes and links, and organize useful findings in Scuba.

## Connect

Install this plugin in your supported client and sign in to your Scuba account when prompted. An existing Scuba account is required. The integration uses the hosted Scuba service at https://api.scuba.app/mcp/.

## Try it

- “Find the Capture about our onboarding decisions.”
- “Read the sources in my Product Research Collection and summarize the main findings.”
- “Save this summary to Scuba as a text Capture.”

## Support and privacy

Contact support@scuba.app. See [privacy policy](https://scuba.app/privacy) and [terms](https://scuba.app/terms).

## Engineering memory skills

This package includes `scuba-setup`, `scuba-codebase-memory`, and
`scuba-review-memory` with their supporting files. Ask your agent to use
`scuba-setup` to select a collection for the adopting repository.
See the [installation and team guide](https://github.com/scuba-app/scuba-plugins).

Maintainers: edit skills at the repository root and run
`python3 scripts/sync-platform-skills.py`; this package contains generated copies.
