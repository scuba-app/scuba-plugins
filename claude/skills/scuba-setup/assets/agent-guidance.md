## Engineering memory

Use the `scuba-codebase-memory` skill before non-trivial engineering work to look
for prior decisions, failed approaches, or incidents relevant to the task. Verify
historical claims against the current code. The destination collection is configured
in `.scuba/config.json`. Offer to record durable conclusions that the code cannot
explain; explicit filing requests already authorize the requested write. Respect
Scuba's audience confirmations. Missing access must not block unrelated coding work.
